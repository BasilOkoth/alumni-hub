# Alumni Circle — Premium Redesign

This is the replacement for the earlier Alumni Hub prototype.

## What changed

- Removed the school-style/demo positioning.
- Removed automatic fake members, fake jobs and the fake "School Library Renewal" project.
- Added a cleanup routine that removes only the exact demo records shipped in the previous version.
- The platform is now group-first, not school-first.
- Premium dark-ink / ivory / gold interface.
- Uses the real model discussed:
  - Welfare Circle
  - Opportunity Exchange
  - People & Skills
  - Shared Legacy
  - Alumni voting
  - WhatsApp Assistant
- Member profiles now emphasise **Can Give** and **Currently Need**.
- The 66-person group size is configurable with `COMMUNITY_SIZE`.
- Community name and tagline are configurable instead of hard-coded to a school.
- Committee financial actions are protected behind an admin access code.
- PostgreSQL / Render support retained.

## Render environment variables

Required / recommended:

```text
SECRET_KEY              generated by Render
ADMIN_PIN               generated by Render; copy it from Render when you need committee access
DATABASE_URL            connected automatically to Render PostgreSQL
BASE_URL                your Render URL, e.g. https://alumni-hub.onrender.com
COMMUNITY_NAME          Alumni Circle
COMMUNITY_TAGLINE       Support each other. Open doors. Build a legacy.
COMMUNITY_SIZE          66
```

WhatsApp integration later:

```text
WHATSAPP_ACCESS_TOKEN
WHATSAPP_PHONE_NUMBER_ID
WHATSAPP_VERIFY_TOKEN
```

## Deploy

Replace the files in your GitHub repository with the contents of this ZIP.

Render:

```text
Build command:
pip install -r requirements.txt

Start command:
gunicorn app:app
```

Health check:

```text
/health
```
