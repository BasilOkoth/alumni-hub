# No fixed member limit

This test build removes the earlier 66-member assumption.

- The dashboard shows the actual number of registered members.
- `COMMUNITY_SIZE` is no longer required.
- There is no application-level membership ceiling.
- New members can continue registering as the alumni network grows.
- The current product remains alumni-focused for pilot testing; it can later be generalized into a multi-community welfare platform without reintroducing a fixed membership target.
